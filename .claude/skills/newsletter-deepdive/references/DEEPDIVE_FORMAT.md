# Deep-Dive Knowledge Base Format

The `deepdive.md` file is a flexible knowledge base that the user prepares before the writing session. It contains research materials, notes, and references related to the deep-dive topic.

This is a **single file** that the user overwrites each week. No version history is needed.

## Accepted Content

The file can contain any combination of:

- **Links** with descriptions or annotations
- **Bullet-point notes** on key concepts
- **Code snippets** or technical examples
- **Quotes** from articles or papers
- **Data points** (benchmarks, statistics, comparisons)
- **Raw thoughts** or unstructured notes
- **References** to tools, papers, or projects

## Example Structure

```markdown
# Deep-Dive: [Argomento]

## Link principali
- [Titolo articolo](URL) - annotazione personale
- [Paper accademico](URL) - risultati chiave: ...

## Punti chiave
- Punto 1 con dati a supporto
- Punto 2 con riferimento a tool X
- Confronto tra approccio A e approccio B

## Dati e benchmark
- Modello X: 95% accuracy su benchmark Y
- Costo: $Z per 1M token

## Note sparse
- Idea da approfondire...
- Collegamento con argomento precedente...
```

## Important
- There is no strict format requirement. The skill will extract relevant information regardless of structure.
- The user's initial deep-dive text is the PRIMARY source. This file is SUPPLEMENTARY material for enrichment.
